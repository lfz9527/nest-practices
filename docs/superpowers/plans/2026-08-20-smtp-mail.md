# SMTP 邮件发送实现计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在现有 NestJS 项目中新增受 JWT 保护的 SMTP 单封纯文本邮件发送能力。

**Architecture:** 新建 `MailModule`，由 `MailController` 暴露 `POST /mail/send`，由 `MailService` 通过 `ConfigService` 读取 SMTP 配置并调用 Nodemailer。服务层导出供后续业务复用，发送错误转换为项目现有 `AppError`。

**Tech Stack:** NestJS 11、TypeScript 5.7、class-validator、@nestjs/config、Nodemailer、Jest 30、pnpm。

## Global Constraints

- 遵循项目无分号、单引号、尾逗号的 Prettier 风格。
- 发送接口不标记 `@Public()`，必须经过全局 JWT 守卫。
- 第一版只支持一个收件人、主题和纯文本正文，不支持 HTML、抄送、密送和附件。
- SMTP 配置必须写入 `config.yaml`，每个字段添加中文注释。
- 不在仓库中提交真实 SMTP 密码或授权码。
- 对外错误不得泄露底层 SMTP 响应、账号密码或错误堆栈。
- 不依赖真实 SMTP 服务，测试使用 mock transporter。

- [ ] **Step 3: Implement the DTO**

Use project validation style:

```ts
import { IsEmail, IsNotEmpty, MaxLength } from 'class-validator'

export class SendMailDto {
  @IsNotEmpty({ message: '收件人不能为空' })
  @IsEmail({}, { message: '收件人邮箱格式不正确' })
  to!: string

  @IsNotEmpty({ message: '邮件主题不能为空' })
  @MaxLength(200, { message: '邮件主题不能超过200个字符' })
  subject!: string

  @IsNotEmpty({ message: '邮件正文不能为空' })
  @MaxLength(10000, { message: '邮件正文不能超过10000个字符' })
  text!: string
}
```
